# FMQA: 대리모형 기반 양자 최적화 (개선판)

## 구조

압력 기반 차단 문제의 목적함수는 MINLP 계산 결과라 QUBO 계수를 직접
만들 수 없다. FMQA(Kitai et al. 2020)는 블랙박스를 2차 모형으로 학습하고,
그 모형을 양자로 최적화하고, 제안된 해를 실제 평가해 학습셋에 넣는 순환이다.

```
비싼 부분: MINLP 압력 평가   <- 고전. 이 횟수를 줄이는 것이 목표
싼 부분:  대리모형 QUBO 최소화 <- 여기에 QAOA / 어닐링
```

## 개선 내용 (v2)

**1. 무작위 탐색 도입 (eps=0.10)**

기존 구현은 대리모형 제안만 따라 국소최적에 갇혔다.
k=5 시행 3,4,5 가 같은 조합 주변만 280회 맴돌며 0.911 에 머물렀다.

무작위 탐색 비율 실측 (k=5, exact, 3회):

| eps | 평균 평가 | 비율 | 편차 |
|---|---|---|---|
| 0.00 (기존) | 228 | 0.941 | 0.042 |
| **0.10** | **211** | **1.000** | **0.000** |
| 0.20 | 221 | 0.970 | 0.042 |

**평가 횟수는 줄고 항상 최적에 도달한다.** 0.10 을 기본값으로 설정.
개선이 `patience`(기본 25) 회 없으면 탐색 비율을 자동으로 2배로 올린다.

**2. QAOA 호출 비용 축소**

대리모형 최소화는 정확한 최소해가 아니라 좋은 후보 하나면 충분하다.

| 항목 | 기존 | 개선 |
|---|---|---|
| QAOA 층수 p | 3 | 2 |
| 재시작 | 6 | 2 |
| COBYLA 반복 | 200 | 60 |
| 샷 | 8192 | 4096 |

**약 6배 빠르다.** 기존 설정으로는 k=3,4 에 5시간 이상 걸렸다.

## 확인된 성능 (개선 후)

| k | 전수 | 탐욕 | FMQA (exact) |
|---|---|---|---|
| 4 | 10,626회 · 1.000 | 0.842 | **105회 (1.0%) · 1.000 ± 0.000** |
| 5 | 42,504회 · 1.000 | 0.767 | **211회 (0.5%) · 1.000 ± 0.000** |

**전수 대비 100~200배 절감하면서 항상 최적을 찾는다.**

## 실행

```powershell
conda activate qaoa
python run_fmqa.py --plan main --workers 20
```

| 계획 | 내용 | 예상 시간 |
|---|---|---|
| `quick` | k=3,4 / exact,sa / 3회 | 약 10분 |
| `main` | k=3,4,5 / exact,sa,qaoa / 5,5,3회 | GPU 1~3시간 |
| `qaoa` | QAOA 만 | GPU 1~2시간 |

개별 실행:

```powershell
python fmqa.py --k 5 --opt exact --n-init 80 --n-iter 200 --repeats 5
python fmqa.py --k 5 --opt qaoa  --n-init 80 --n-iter 200 --repeats 3
python fmqa.py --k 5 --opt exact --eps 0.0    # 개선 전 동작 (비교용)
```

## 결과 해석

**핵심 지표는 MINLP 평가 횟수**다. 전수 대비 몇 %로 최적을 찾는가.

| 지표 | 의미 |
|---|---|
| 평균 평가수 | 적을수록 좋음 |
| 무작위 N회 | 탐색으로 소모한 횟수 |
| 비율 | 찾은 값 / 실제 최적. 1.000 이 최적 도달 |
| 편차 | 0 이면 항상 최적 도달 |

`exact` / `sa` / `qaoa` 의 **평가수와 비율이 비슷하면**
"대리모형 최적화에 양자를 써도 성능이 유지된다" 는 결론이 된다.

## 정직하게 짚을 것

- 현 규모(24큐빗, k<=5)에서는 대리모형 전수 최소화가 즉시 되므로
  양자가 필요 없다. QAOA 의 의미는 k 가 커질 때다.
  k=8 이면 735,471 조합, k=12 면 270만 조합.
- 논문에서는 "현 규모 성능 동등, 확장 시 필요" 로 서술할 것.
- eps 도입은 FMQA 원논문에 없는 본 연구의 추가다. 명시할 것.
